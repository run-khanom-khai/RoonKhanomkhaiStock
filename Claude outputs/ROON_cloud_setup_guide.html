☁️ คู่มือขึ้น Cloud ระบบ ROON (ทีละขั้น)

ให้ระบบอยู่บนเน็ตตลอด ไม่หลับ · พนักงานเปิดใช้ผ่าน "ลิงก์" · ไม่ต้องดูแลเทคนิค

ต้องเช่า 2 อย่าง: ① Supabase Pro (ฐานข้อมูล + backup อัตโนมัติ ~$25/เดือน) และ ② Render (ที่รันแอป ไม่หลับ ~$7/เดือน) · รวม ~$32/เดือน (~1,100 บาท)
💳 น้องเก่งกรอกบัตร/สมัครแทนไม่ได้ (เพื่อความปลอดภัยของบัตร ดร.วรรณ) — คู่มือนี้ให้ ดร.วรรณ กดตามเองทีละขั้น ตรงช่องกรอกบัตรให้ ดร.วรรณ พิมพ์เอง · ที่เหลือน้องเก่งบอกให้กดตรงไหนหมดแล้ว
🖼️ ภาพในคู่มือนี้เป็น "ภาพจำลอง" ให้เห็นว่าหน้าตาประมาณไหน/ต้องกรอกอะไร (ของจริงบนเว็บอาจต่างเล็กน้อย แต่ปุ่มจะชื่อเดียวกัน)

ส่วน A · อัปเกรด Supabase เป็น Pro (ฐานข้อมูล + backup)

1
เปิด supabase.com → กด Sign in เข้าด้วยบัญชีเดิมที่มีโปรเจกต์ ROON อยู่
2
คลิกเข้า โปรเจกต์ ROON → เมนูซ้ายล่าง Settings ⚙️
3
เลือก Billing (หรือ Subscription) → กด Upgrade to Pro
supabase.com · Settings › Billing
Free (ปัจจุบัน) ✔ Pro ~$25/mo
Upgrade to Pro
4
กรอกบัตรเครดิต/เดบิต (👉 ดร.วรรณ พิมพ์เอง) → ยืนยัน
5
เปิด backup อัตโนมัติ: Database → Backups → ดูว่ามี Daily backups เปิดอยู่ (แผน Pro จะมีให้อัตโนมัติ)
✅ เสร็จส่วน A: ฐานข้อมูลไม่หลับแล้ว + สำรองข้อมูลให้ทุกวัน

ส่วน B · เอาแอป roon_app ขึ้น Render (ที่รันแอป ไม่หลับ)

1
เปิด render.com → Get Started / Sign up → เลือก Sign in with GitHub (ใช้บัญชี GitHub เดียวกับที่เก็บโค้ด ROON) → กด Authorize
2
ที่หน้า Dashboard กด New + → เลือก Web Service
dashboard.render.com
+ New → Web Service
3
เลือก repo RoonKhanomkhaiStock → กด Connect
4
กรอกค่าตั้งค่า (คัดลอกตามนี้เป๊ะๆ):
Render · Create Web Service
Name (จะกลายเป็นลิงก์)
roon-app
Branch
main
Build Command
pip install -r requirements.txt
Start Command
streamlit run roon_app.py --server.port $PORT --server.address 0.0.0.0
Instance Type (แผน)
Starter — $7/mo (สำคัญ! ห้ามเลือก Free เพราะ Free จะหลับ)
คัดลอก Start Command ไปวางได้เลย:
streamlit run roon_app.py --server.port $PORT --server.address 0.0.0.0
5
ใส่รหัสต่อฐานข้อมูล (Secret File) — เลื่อนหา Advanced → Secret Files → Add Secret File:
Render · Secret Files
Filename (พิมพ์ให้ตรงเป๊ะ)
.streamlit/secrets.toml
Contents (วางข้อความ Secrets เดียวกับที่ใช้บน Streamlit Cloud เดิม)
[supabase]
url = "https://xxxx.supabase.co"
key = "eyJ....(รหัสยาว)...."
👉 ก๊อป Secrets ตัวจริงมาจาก: แอปเก่าบน Streamlit Cloud → Manage app → Settings → Secrets (วางทั้งก้อน)
6
กด Create Web Service → รอ Render build ~3–5 นาที จนขึ้น Live (สีเขียว)
7
ได้ ลิงก์แอป ด้านบน เช่น https://roon-app.onrender.com → เปิดทดสอบล็อกอินทุกแผนก
✅ เสร็จส่วน B: แอปอยู่บนเน็ตตลอด ไม่หลับ มีลิงก์เดียวใช้ได้ทั้งบริษัท

ส่วน C · ส่งให้พนักงานใช้ (ไม่ต้องมี bat!)

เข้าใจให้ตรงกัน: พนักงาน ไม่ต้องใช้ไฟล์ bat และ ไม่ต้องลงโปรแกรมอะไร — แค่เปิด ลิงก์ ที่ได้จากส่วน B บนมือถือ/คอมพิวเตอร์ แล้วล็อกอิน (bat เป็นแค่ของไว้รันในเครื่อง ดร.วรรณ เท่านั้น)
1
ก๊อปลิงก์ (เช่น https://roon-app.onrender.com) ส่งให้พนักงานทางไลน์กลุ่ม
2
แนะนำพนักงาน: เปิดลิงก์ → กด "เพิ่มไปหน้าจอหลัก" (Add to Home Screen) จะได้ไอคอนเหมือนแอปบนมือถือ
3
พนักงานสำนักงาน → แท็บ "🏢 พนักงานสำนักงาน/แผนก" · พนักงานสาขา → แท็บ "🏪 พนักงานสาขา" (เลือกสาขา→รหัสของสาขา)

📌 สิ่งสำคัญหลังทำเสร็จ

เรื่องต้องทำ
บิลรายเดือนทั้ง Supabase Pro (~$25) และ Render Starter (~$7) ตั้งตัดบัตรอัตโนมัติ · อย่าให้บัตรหมดอายุ
ปิดแอปเก่าเมื่อลิงก์ใหม่ใช้ดีแล้ว ค่อยปิดแอปเก่า 7 ตัวบน Streamlit Cloud (ประหยัด/ไม่สับสน)
ถ้าแอปช้า/ค้างเข้า Render → กดปุ่ม Manual Deploy → Restart รอ 1–2 นาที
รหัสสำคัญเก็บรหัส GitHub / Supabase / Render ไว้ที่เดียว บอกลูกชายว่าอยู่ไหน
🔐 อย่าโพสต์บรรทัด key ของ Supabase ที่สาธารณะเด็ดขาด (เป็นกุญแจเข้าฐานข้อมูลทั้งหมด)
