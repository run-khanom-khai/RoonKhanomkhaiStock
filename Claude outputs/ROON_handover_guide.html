🛒 คู่มือส่งมอบระบบ ROON ให้ใช้ระยะยาว

เทียบค่าใช้จ่าย · ขั้นตอนย้ายขึ้นระบบ Managed (ไม่ต้องดูแล) · คู่มือส่งมอบให้ลูกชาย

จัดทำโดย ดร.วรรณ (ดร.อภิวรรณ์ ดำแสงสวัสดิ์)

เป้าหมาย: ตั้งค่าครั้งเดียว แล้วส่งมอบให้ลูกชายใช้เองได้ โดยแทบไม่ต้องดูแลเทคนิค — เหลือแค่ "จ่ายบิลรายเดือน + กดปุ่มเดียวถ้าต้อง restart"

ส่วนที่ 1 · เทียบค่าใช้จ่าย (3 ทาง)

ระบบมี 2 ส่วนที่ต้องมี "ที่อยู่": ฐานข้อมูล (Postgres) และ ตัวแอป (Streamlit). ทุกทางใช้ Postgres ฟรี (ไม่มีค่า license) เหมือนกัน — ต่างกันที่ "ใครดูแลเซิร์ฟเวอร์"

ทางค่าใช้จ่าย/เดือนใครดูแลเหมาะกับ ดร.วรรณ ไหม
A. ฟรีทั้งหมด
(Streamlit Cloud ฟรี + Supabase ฟรี)		0 บาท อัตโนมัติ แต่แอปหลับหลังไม่ใช้ ~12 ชม. + DB pause 1 สัปดาห์ พอใช้ทดลอง แต่ช้า/หลับ ไม่เหมาะใช้จริงจัง
B. Managed จ่ายรายเดือน แนะนำ
(โฮสต์แอป + Supabase Pro)		 ~1,200 บาท (~$35) ผู้ให้บริการดูแลให้หมด — backup อัตโนมัติ ไม่หลับ ไม่ต้องแตะเทคนิค ใช่ — เหมาะที่สุด สำหรับส่งมอบให้คนไม่เทคนิค
C. ติดตั้งเองบน VPS
(เช่าเซิร์ฟเวอร์ ลง Postgres เอง)		~200–400 บาท ต้องดูแลเอง — อัปเดต ความปลอดภัย ตั้ง backup เอง ไม่เหมาะ ถูกสุดแต่ถ้าไม่มีคนดูแล เสี่ยงข้อมูลหาย/โดนแฮก
💡 ตัวคูณค่าใช้จ่ายที่สำคัญ: ตอนนี้ระบบแยกเป็น 7 แอป ถ้าโฮสต์แบบคิดต่อแอปจะแพงขึ้นหลายเท่า → ถ้ารวมเหลือ 1 แอป จะจ่ายค่าโฮสต์แค่ก้อนเดียว (ดูส่วนที่ 4)

* ราคาโดยประมาณ ณ ปี 2026 — ควรตรวจสอบราคาจริงตอนสมัครอีกครั้ง

ส่วนที่ 2 · ขั้นตอนย้ายขึ้นระบบ Managed (ทีละขั้น)

1
รวม 7 แอป → 1 แอป ก่อน (ให้น้องเก่งทำให้) — เพื่อให้เหลือของที่ต้องโฮสต์แค่ชิ้นเดียว ถูกและง่ายกว่ามาก
2
อัปเกรด Supabase เป็นแผน Pro — เข้า supabase.com → โปรเจกต์ ROON → Settings → Billing → เลือก Pro (~$25/เดือน) → เปิดใช้ Daily Backups (backup อัตโนมัติทุกวัน)
3
สมัครโฮสต์แอปแบบไม่หลับ (เช่น Render หรือ Railway) → เชื่อมกับ GitHub repo เดิม → ตั้งค่า Secrets (คีย์ Supabase) เหมือนที่ตั้งใน Streamlit → Deploy
4
ทดสอบให้ครบ — ล็อกอินทุกแผนก บันทึกข้อมูลจริง 2–3 วัน ดูว่าไม่หลับ + เร็วขึ้น
5
ผูกบัตร/ตั้งจ่ายอัตโนมัติ ทั้ง Supabase และโฮสต์แอป เพื่อไม่ให้ระบบสะดุดเพราะลืมจ่าย
✅ เสร็จแล้วระบบจะ เปิดตลอด 24 ชม. · เร็วขึ้น · backup ข้อมูลอัตโนมัติทุกวัน โดยไม่ต้องดูแลเทคนิค

ส่วนที่ 3 · คู่มือส่งมอบให้ลูกชาย (First)

สิ่งที่ลูกชายต้องรู้มีแค่นี้ — ไม่ต้องเขียนโปรแกรมเป็น:

🔑 การเข้าใช้งานประจำวัน

  • เปิดลิงก์แอป (บุ๊กมาร์กไว้) → ล็อกอินด้วยรหัสแผนกของตัวเอง → ใช้งานได้เลย
  • พนักงานแต่ละแผนกมีรหัสของตัวเอง (ดูจากคู่มือรหัสผ่าน)

💳 บิลรายเดือน (สำคัญ — อย่าให้ขาด)

  • Supabase (ฐานข้อมูล) ~$25 · โฮสต์แอป ~$7–10 — ตั้งตัดบัตรอัตโนมัติไว้
  • ถ้าบัตรมีปัญหา บริการจะส่งอีเมลเตือน → ต้องรีบอัปเดตบัตร ไม่งั้นระบบหยุด

🔄 ถ้าแอปช้า/ค้าง (แก้เองได้)

  • เข้าหน้าจัดการแอป (Render/Railway) → กดปุ่ม Restart / Reboot → รอ 1–2 นาที
  • ยังไม่หาย → ดูส่วน "ติดต่อใคร" ด้านล่าง

💾 ข้อมูลปลอดภัยแค่ไหน

  • Supabase Pro backup อัตโนมัติทุกวัน — ถ้าข้อมูลผิดพลาด กู้คืนย้อนหลังได้
  • ไม่ต้องทำ backup เอง

📞 ถ้ามีปัญหาที่แก้เองไม่ได้ (ติดต่อใคร)

  • ผู้ดูแลระบบ / ผู้พัฒนา: __________________ (เบอร์/ไลน์: __________)
  • บัญชี GitHub (เก็บโค้ด): user __________ / รหัส __________
  • บัญชี Supabase: อีเมล __________
  • บัญชีโฮสต์แอป (Render/Railway): อีเมล __________
🔐 เก็บรหัสผ่านทั้งหมดไว้ที่เดียว (สมุด/ไฟล์ที่ปลอดภัย) และบอกให้ลูกชายรู้ว่าเก็บไว้ที่ไหน

ส่วนที่ 4 · แผน "รวม 7 แอป → 1 แอป" (งานถัดไป)

ทำไมต้องรวม: เหลือ 1 URL · 1 ที่ต้องดูแล · ค่าโฮสต์ก้อนเดียว → ง่ายและถูกที่สุดสำหรับส่งมอบ

หลักการ: แอปเดียว พอล็อกอินด้วยรหัสแผนกไหน ระบบจะแสดงเฉพาะเมนูของแผนกนั้น (บัญชี/จัดซื้อ/ผลิต/ตรวจสอบ/สาขา/Sale Audit/ผู้บริหาร) — โค้ดเดิมใช้ต่อได้เกือบทั้งหมด แค่รวมทางเข้า

น้องเก่งจะทำส่วนนี้ให้เป็นสเต็ปถัดไป (แยกทำเพื่อความรอบคอบ ทดสอบทุกแผนกก่อนส่งมอบ)
